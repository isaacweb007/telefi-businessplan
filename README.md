# TeleFi 텔레파이 — 사업계획서

텔레그램 미니앱 + 웹으로 동시 출시하는 크립토 전용 카지노 사업계획서입니다.
슬롯 · 카드(테이블) · 라이브 카지노 · 미니게임을 다루며 스포츠북은 제외합니다.

**문서 보기 → https://isaacweb007.github.io/telefi-businessplan/**

## 담긴 내용

- 시장 분석 — 온라인 겜블링, 크립토 카지노, 텔레그램 미니앱 경제
- 제품 — 미니앱 우선 전략과 웹 병행 근거
- 게임 버티컬별 경제 구조 (하우스 엣지 · 콘텐츠 요율 · 믹스)
- **인터랙티브 수익 시뮬레이터** — 유저 수 · 베팅액 · 프로모션 · 운영비 · 게임 믹스 조정
- 투자 및 비용 구조, 5개월 런칭 로드맵, GTM, 리스크 대응
